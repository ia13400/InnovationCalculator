# InnovationCalculator

Innovationsrendite-Rechner nach dem Inno-Rendite-Kalkulator von Prof. Dr. Gerhard Hube (THWS) – Trend2Business-Projekt SpaceX, Gruppe 2.

- `index.html` ist die komplette Website (keine Abhängigkeiten, kein Server).
- Hosting: GitHub → Settings → Pages → Branch `main`, Ordner `/ (root)`.
- Rechenlogik: IR = IN / IA, Bilanz = IN − IA, Portfolio-Kategorien < 2 / 2–3 / ≥ 3; 5-Jahres-Kalkulation mit Gewinnanteil- und Kostenanteil-Skala wie im Excel-Tool.
- Daten werden im Browser gespeichert; Austausch über Export/Import (JSON) unter „Gewichtung & Daten“.

## Teil 6: Roadmap & Maßnahmenplan (im Reiter „RocketLight Dinner“, Direktlink `#roadmap`)

- Der Dinner-Reiter hat zwei Gruppen: „Das Dinner“ (01–04) und „Umsetzung · Teil 6“ (05–10).
- Umsetzung: Überblick mit Stage-Gates und Variantenvergleich, 4 W-Fragen, Teilprojekte (Projektzusammenfassung Teil 1), Budget (Teil 2), Roadmap im Format nach Hube und Quellen.
- Umschalter zwischen Variante A (mobiler Pavillon, passt zu Kalkulator und 5P-Mix) und Variante B (feste Lounge in Titusville); die Wahl wird im Browser gespeichert.
- Die Roadmap ist eine SVG-Grafik: Zeile anklicken für Details, Elemente überfahren für Datum und Bezeichnung.
- Die passenden Folien liegen als PPTX in `praesentation/` (je 6 Folien im Design der Gruppenpräsentation, mit Sprechernotizen).
